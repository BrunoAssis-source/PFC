Política de privacidade

O UniData utiliza os dados informados no cadastro para controlar o acesso ao sistema e orientar a coleta de dados de pesquisa.

Dados coletados

São armazenados nome completo, email institucional e perfil de acesso. A senha é guardada como hash, pelo mecanismo do Django.

Uso dos dados

Os dados são usados para autenticação, controle de permissões e registro das operações realizadas no sistema. O cadastro é restrito a quem tem email do domínio institucional. O perfil de acesso é escolhido no cadastro e pode ser corrigido pela administração do sistema.

Direitos do titular

Solicitações sobre acesso, correção ou exclusão de dados devem ser encaminhadas à administração do sistema.
